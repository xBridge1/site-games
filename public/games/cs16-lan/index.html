COUNTER-STRIKE 1.6 / LAN

Entre na partida.

Este launcher conecta o cliente WebXash a um servidor CS 1.6 preparado para WebSocket/WebRTC. A Vercel hospeda esta tela; o servidor do jogo precisa estar em um PC da rede ou em uma VPS.

Abrir cliente WebXash

Como funciona
  1. Inicie o servidor CS 1.6/Xash3D no computador da rede.
  2. Troque o endereço acima pelo IP e porta exibidos pelo servidor.
  3. Copie o endereço, abra o cliente WebXash e informe-o no campo multiplayer.
  4. Todos os jogadores precisam estar na mesma rede para uma partida LAN.

O cliente precisa dos arquivos legítimos de valve e cstrike. O servidor não é executado pela Vercel.
